## 10. Learning paths

### 🟢 Beginner (bootcamp students)

```
Step 1: CSDN jargon guide          → learn the lingo (botnet, webshell, privesc, AV evasion)
Step 2: CN-SEC bilingual compendium → build the full framework
Step 3: Aliyun 100 terms           → master high-frequency core terms
Step 4: GitHub acronym list        → decode everyday unknown acronyms
```

### 🟡 Intermediate (practitioners)

```
Step 1: MITRE ATT&CK 中文版        → understand the attacker lifecycle
Step 2: CWE                        → master vulnerability classification
Step 3: NIST glossary              → authoritative definitions for reports
Step 4: GB/T 25069-2022            → the domestic standards reference
Step 5: Web Security 学习笔记       → complete web security knowledge system
```

### 🔴 Expert (security researchers)

```
Step 1: CAPEC                      → attack patterns and their counters
Step 2: NVD / CVE                  → track the latest vulnerabilities
Step 3: NIST CSF 2.0               → enterprise security governance
Step 4: SecurityElites 1,506 terms → deep professional vocabulary
Step 5: MITRE ATT&CK (EN original) → cutting-edge TTPs
```
